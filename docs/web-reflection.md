# Web UI Reflection

## CLI vs Web UI

The CLI calculator collects input from the user through the terminal using
Java's `Scanner` class. The user enters the first number, operator, and
second number as text in separate prompts. The web calculator presents a
graphical interface with a display and buttons, allowing users to interact
with the calculator visually. Unlike the CLI version, the web interface
provides a more visual and user-friendly way to enter calculator input.

## JavaScript

JavaScript would be required to make the calculator buttons functional,
process button clicks, perform calculations, and update the display with
the result.

## DevTools Network Observation

When the page is loaded, the browser requests the HTML document and the
linked CSS stylesheet. The Network tab can be used to observe these
requests when the page is reloaded.
